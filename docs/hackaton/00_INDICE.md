## Criterios de evaluación

| Criterio | Peso | Apuesta de eVoting |
|----------|------|--------------------|
| Impacto tecnológico | 30% | Necesidad real: elecciones institucionales seguras, secretas y auditables |
| Innovación | 30% | Cifrado en cliente, urna sin identidad, escrutinio offline firmado, verificación pública |
| Software funcional | 30% | Demo viva + repo + vídeo + docs |
| AWS y Kiro | 10% | Kiro (steering/agentes/skills) + mapa AWS (actual / roadmap) |
